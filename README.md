# Prompts Library — M. WAHBA

AI prompts Mohamed collects to keep, test and improve.

## Rules
1. **Never delete.** Originals stay as `v1.md`. Improvements are added as `v2.md`, `v3.md`… next to them.
2. Reviews propose changes; nothing replaces a version until Mohamed approves.
3. Target: every set scores **9/10** on the rubric (`RUBRIC.md`).
4. Real test results go in `lessons.md` — that's what drives improvement.

## Layout
```
sets/<set-name>/v1.md        original, as received
sets/<set-name>/v2.md        approved improvement (when it exists)
sets/<set-name>/notes.md     source, test results, open issues
reviews/YYYY-MM-DD.md        twice-weekly review (Sun & Wed)
RUBRIC.md                    scoring criteria
lessons.md                   what we learned from real use
INDEX.md                     all sets + latest score
```
