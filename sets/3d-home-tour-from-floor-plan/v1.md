# 3D Home Tour from a Floor Plan — 7 Prompts (v1, original)

Source: Instagram @godofprompt (carousel, Nov 2026)
Setup: Pick Fable 5.2 in the model menu. Upload a photo or PDF of any floor plan.
Run the prompts in order, in the same chat.

---

## 1/7 · The Plan — Read the blueprint first

```
You're an architectural visualizer who makes 3D home tours for builders. I uploaded a 2D floor plan. Read it carefully: list every room with its size, every door, window and stair, and the wall height you'll use. Point out anything unclear. Then plan a 3D walkthrough of this home: the style and materials for each room, the lighting, the furniture, and the path a buyer would walk from the front door. Don't write code yet.
```

## 2/7 · The Build — Build the home in 3D

Runs in the chat. No 3D software, no models to download.

```
Now build it as one HTML file with Three.js. Match the plan exactly: walls, doors, windows and room sizes to scale. Add real-looking floors, walls and ceilings, furniture that fits each room, and soft daylight coming through the windows. Let me walk through it in first person with WASD and the mouse. Add a top-down dollhouse view with the roof off that I can switch to with one button.
```

## 3/7 · The Style — Furnish it like a pro designer

```
Furnish every room the way a high-end interior designer would for a listing, in [modern / Scandinavian / warm luxury] style. Add rugs, art, plants, lamps, a set dining table, made beds and kitchen details. Make the materials feel real: wood grain, stone counters, soft fabric. Then add a style switch so I can show the same home in 3 different styles with one click.
```

## 4/7 · The Light — Show it at sunset and at night

```
Add a time-of-day slider from morning to sunset to night. Move the sunlight through the windows as I drag, make it warm and golden at sunset, and at night turn on the lamps and ceiling lights with a soft glow. Add soft shadows and a light reflection on the floors and glass. Keep every change smooth and keep it running well on a normal laptop.
```

## 5/7 · The Tour — Add a guided tour for buyers

```
Add a Start Tour button. The camera walks slowly from the front door through every room in order, pausing in each one with a small label: the room name, its size in square feet and one selling point. Add soft background music made with code, no sound files, and a mute button. At the end, rise up to the dollhouse view of the whole home.
```

## 6/7 · The Share — Make it ready for the client

Then publish the artifact for a shareable link, or screen-record the tour for a listing video.

```
Make this ready to send to a client. Add a clean welcome screen with [project name, address, price] and a Start button, a level switch if the home has more than one floor, and a contact button with [your name and phone]. Make it work on phones with touch controls. Then check every room against the floor plan and fix anything that doesn't match.
```

## 7/7 · The Client — Sell it to a builder

Post claims tours like this sell for $5,000–$10,000 per plan (unverified marketing claim). Make one free first, then pitch.

```
Write a DM to [home builder or architect] who sells homes before they're built. I turned one of their floor plans into a 3D tour buyers can walk through on their phone: [link]. The offer: a tour for every plan they're selling, [your price] per plan, ready in 5 days. Friendly and simple, under 70 words. Then write my reply if they say it's too expensive.
```
